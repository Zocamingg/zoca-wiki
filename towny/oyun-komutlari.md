# 📈 Oyun Komutları

### Towny Komutları;

* /town {Kasaba İsmi} - Başka bir kasaba hakkında bilgi verir.
* /town here - Bulunduğunuz alanda kasaba hakkında bilgi verir.
* /town leave - Bulunduğunuz kasabadan ayrılmanızı sağlar.
* /town list - Sunucudaki kasaba listesini gösterir.
* /town online - Kasabada ki aktif oyuncuları gösterir.
* /town new - Kasaba kurmanızı sağlar.
* /town invite - Kasabanıza oyuncu almanızı sağlar.
* /town kick - Kasabanızdan oyuncuyu atmanızı sağlar.
* /town spawn - Kasabanızın spawn noktasına ışınlanmanızı sağlar.
* /town spawn - Herhangi bir kasabanın ışınlanma noktasına gitmenizi sağlar.
* /town claim - Bulunduğunuz chunk'ı kasabanıza almanızı sağlar.
* /town claim outpost - Kasabanızdan uzak bir yere claim almanızı sağlar.
* /town outpost {1} - {9} - Kasabanızdan uzak claimlere ışınlanmanızı sağlar.
* /town unclaim - Bulunduğunuz chunk'ı kasabanızdan kaldırır.
* /town withdraw - Kasabanın bankasından para çeker.
* /town deposit - Kasabanın kasasına para ekler.
* /town ranklist - Vatandaşların rütbelerini gösterir.
* /town rank - - {rütbe} - Kasabanızdaki üyeye rütbe vermenizi sağlar.
* /town rank - - {rütbe} - Kasabanızdaki üyenin rütbesini kaldırmanızı sağlar.
* /town reslist - Kasabadaki üyeleri listeler.
* /town join - Davet gerektirmeyen kasabalara girmenizi sağlar.
* /town outlaw add - Herhangi bir oyuncuyu kasabanızda haydut ilan edersiniz.
* /town outlawlist - Haydut ilan ettiğiniz oyuncuları listeler.
* /town bankhistory - Kasabanın banka geçmişini gösterir.
* /town delete - Yeterince yetkiniz varsa kasabanızı silmenizi sağlar.
* /town plots - Kasaba plotları hakkında detaylı bilgi verir.
* /town plotgrouplist - Kasabanızda ki plot gruplarının listesini gösterir.
* /town purge {gün sayısı} - Kasabanızda ki üyelerin, belirli gün oyuna girmeyenleri toplu atmanızı sağlar
* /town say - Kasabanızda duyuru yapmanızı sağlar
* /town trust - Belirlenen oyuncuya kasabanızda ki bütün her yerde yetki vermenizi sağlar, **güvenmediğiniz kişilere trust vermeyiniz!**
* /town merge - İki kasabayı birleştirmenizi sağlar.

### [#](https://kitap.mavibugday.com/towny/komutlar/#towny-toggle-komutlar%C4%B1)Towny **Toggle** Komutları

* /town toggle explosion on/off - Kasaba içindeki patlama hasarlarını açıp kapatır.
* /town toggle fire on/off - Kasaba içindeki blok yanmalarını açp kapatır.
* /town toggle mobs on/off -Kasaba içindeki yaratık doğmasını ve yaratıkların bulunmasını ayarlar.
* /town toggle nationzone on/off - Kasaba içindeki ulus bölgelerini ayarlar.
* /town toggle neutral on/off - Kasaba'nın barışcıllık durumunu değiştirir.
* /town toggle peacuful on/off - Kasaba'nın barışcıllık durumunu değiştirir.
* /town toggle open on/off - Kasaba'nın davetsiz katılımlara açılmasını sağlar.
* /town toggle public on/off - Kasaba'nın spawn noktasına ışınlanmayı herkese açar.
* /town toggle pvp on/off - Kasabadaki pvpyi ayarlar.
* /town toggle taxpercent on/off - Yüzde esaslı vergileri ayarlar.

### [#](https://kitap.mavibugday.com/towny/komutlar/#towny-set-komutlar%C4%B1)Towny **Set** Komutları

* /town set - Kasaba hakkındaki değişiklikleri ayarlamak için kullanılır.
* /town set board - Kasabanın açıklamasını ayarlar
* /town set mayor - Kasabanın başkanını seçer.
* /town set homeblock - Kasabanın başlangıç chunkını ayarlar.
* /town set spawn - Kasabanın başlangıç chunkını ayarlar.
* /town set spawncost - Kasabanıza ışınlanan yabancılardan ne kadar para kesiceğinizi belirlersiniz.
* /town set name - Kasabanın adını değiştirir.
* /town set outpost Bulunduğunuz outpostun spawn noktasını ayarlar.
* /town set tag - Kasabanın tagını ayarlar.
* /town set mapcolor - Kasabanın haritadaki rengini değiştirir.
* /town set surname {Soyİsim} - Oyuncuya bir soy ad verir.
* /town set title {İsim} - Oyuncuya kendi oluşturduğunuz bir herhangi bir ismi verir.
* /town set embassyprice - Kasaba arazileri içindeki elçiliklerin satış fiyatını belirler.
* /town set embassytax - Kasaba içindeki elçiliklerin kiralarını belirler.
* /town set taxpersentcap - Kasaba içindeki maksimum vergi oranını ayarlar.
* /town set taxes - Kasaba içindeki vergiyi ayarlar.
* /town set plotprice - Kasaba içindeki satılık arazilere ortak fiyat verir.
* /town set plottax - Kullanılan kişisel plotlara, plot başına vergi ayarlar.
* /town set shopprice - Kasaba içinde shop açma fiyatını belirler.
* /town set shoptax - Town içindeki shopların vergisini belirler.

### [#](https://kitap.mavibugday.com/towny/komutlar/#towny-set-perm-komutlar%C4%B1)Towny **Set perm** Komutları

* /town set perm - Oyuncuların kasabadaki yetkilerini ayarlar.
* /town set perm on/off - Oyundaki tüm gruplar için kasabadaki yetkilerin tümünü ayarlar.
* /town set perm on/off - Kasaba içinde belirli bir gruba kasabadaki tüm yetkileri ayarlar.
* /town set perm reset - Kasaba içindeki yetkileri resetler (Dikkat edin bu komut kasabanızdaki yetkileri yabancılara karşı da açar).

### [#](https://kitap.mavibugday.com/towny/komutlar/#towny-siegewar-komutlar%C4%B1)Towny **siegewar** Komutları

* /sw hud {Ulus İsmi} - Aktif olarak devam eden savaşın bilgilerini gösterir.
* /n enemy add {Ulus İsmi} - Bir ulusa düşmanlık ilan edersiniz.
* /n ally add {Ulus İsmi} - Bir ulusa müttefiklik daveti yollarsınız.
* /t toggle peaceful off - Barışçıl olmayı kapatır. {5 Gün sonunda barışçıldan çıkarsınız.}
* /sw nation paysoldiers - Askerlere belirli miktarda altın verir.
* /nation siegewar occupiedforeigntowns - İşgal ettiğiniz yabancı kasabaları gösterir.
* /sw nation removeoccupation - Ulusunuzun işgal ettiği bir kasabanın işgalini kaldırmasını sağlar.
* /nation siegewar occupiedhometowns - Ulusunuzdaki işgal edilen kasabaları gösterir.
* /sw collect - Ganimet sandığını toplar.
* /sw preferance beacons on/off - Siege'de feneri kapatıp açmanızı sağlar.

### [#](https://kitap.mavibugday.com/towny/komutlar/#ulus-komutlar%C4%B1)Ulus Komutları

* /n bankhistory - Ulusunuzda ne kadar para olduğunu ve ne zaman artıp azaldığını görebilirsiniz.
* /n rank add/remove - Ulusunuzdaki üyeye rütbe vermenizi sağlar.
* /n leave - Ulustan çıkmanızı sağlar.
* /n enemey add - Ulusunuza düşman ulus eklemenizi sağlar.
* /n kick - Ulustan istediğiniz herhangi bir kasabayı atmanızı sağlar.
* /n set king - Ulusu seçtiğiniz kişiye devreder.
* /n join - Herkese açık olan uluslara katılmanızı sağlar.
* /n set name - Ulusunuzun ismini değiştirmesini sağlar.
* /n toggle public on - Ulusunuzu herkese açık/davetsiz katılımları açmanızı sağlar.
* /n set spawncost - Ulusunuzun spawn ücretini belirlemenizi sağlar.
* /nc - Ulus sohbete katılmanızı sağlar. (/g komutu ile ulus sohbetten çıkabilirsiniz.)
* /n delete - Komutu ile ulusunuzu silebilirsiniz.
* /n set spawn - Komutu ile ulus spawnını ayarlayabilirsiniz.
