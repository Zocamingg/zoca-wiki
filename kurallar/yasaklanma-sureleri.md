# 🚫 Yasaklanma Süreleri

Bazen bazı oyuncular oyunun adaletini veya huzurunu bozabilecek kötülükler yapabiliyor ve uzaklaştırılmaları gerekiyor. Bu nedenle, hem _otomatik_ hem de _manuel_ olmak üzere sunucumuzda denetlenen yasaklama kuralları bulunmakta:<br>

| Tür 📒             | Ceza 🔨              | Açıklamalar 🗒️                                                                                                                                                                |
| ------------------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Hile Kullanımı     | **30 Gün** ⛔         | Anlatmaya gerek yok.                                                                                                                                                           |
| Hile Kontrol Reddi | **30 Gün** ⛔         | Kontrole çağırıldığı halde gitmemek.                                                                                                                                           |
| Hile Yardım        | **14 Gün** ⛔         | Hile kullanan kişiye yardım yapıldığında uygulanır.                                                                                                                            |
| Dolandırıcılık     | **10 Gün** ⛔         | Başka bir oyuncuyu konu fark etmeksizin kandırmak.                                                                                                                             |
| Grief              | **3 Gün** ⛔          | Bir arazinin etrafını yok etmek. (Geri alınır)                                                                                                                                 |
| Işınlanma Tuzağı   | **7 Gün** ⛔          | Oyuncuların güvenli veya tuzaklı konumlara ışınlandırılması.                                                                                                                   |
| Reklam             | **Perma** ⛔          | Kasıtlı yapılmadığı kanıtlanırsa ceza **1 gün**'e indirilebilir.                                                                                                               |
| Uygunsuz İsim      | **Perma** ⛔          | Küfürlü/hakaret veya cinsellik içeren isimlerin kullanımı.                                                                                                                     |
| Zararlı Linkler    | **Perma** ⛔          | RAT veya IP logger içeren linklerin paylaşımı.                                                                                                                                 |
| Bug Kullanımı      | **7 Gün**/**Perm** ⛔ | <p>Açıkların haksız kazanç amacıyla suistimal edilmesi.<br>! Toplu kullanım veya yardım <strong>hile yardıma</strong> girer.<br>! Bugun ciddiyetine göre perma atılabilir.</p> |

{% hint style="info" %}
**İtiraz**

Hiçbir ceza kanıtsız uygulanmamaktadır, geçerli bir itiraz materyaliniz bulunmadığı sürece itirazda bulunmayınız.
{% endhint %}
